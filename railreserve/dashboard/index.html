Both races fire 20 attempts for the target seat. The safe race uses the conditional update and unique hold index. The browser may hold some attempts back because of its per-host connection limit; the CLI script sends all 20 at once.

Event log

    Safe hold

    A single UPDATE ... WHERE status='available' takes a row lock. A partial unique index allows only one active hold per seat.

    Naive hold

    Read availability, wait, then write without a guard. Every request can pass the read and create its own winner.

    Idempotent payment

    The payment key is unique. Replaying the same request returns the original booking and PNR instead of charging twice.
